# DentaCare — التحديثات / Updates

هذا المستودع يحمل ملف التحديث `latest.json` وملفات التنصيب (في Releases) لبرنامج DentaCare لإدارة عيادات الأسنان.
البرنامج يتحقق من توقيع الناشر (Ed25519) ومن بصمة ملف التنصيب (SHA-256) قبل أي تحديث، فلا يُثبَّت ملف غير موقّع.

This repository hosts `latest.json` and the installers (under Releases) for DentaCare.
The app verifies the publisher's Ed25519 signature and the installer's SHA-256 before installing any update.
